# EZ Scene Collab

Work on the same Unity scene.

## Short description

Collaborative scene editing inside Unity. Watch a host and client move, rotate and create objects in a shared scene, then pass ownership of an object between Editors.

## Video description

EZ Scene Collab Full Edition, recorded in two connected Unity Editors. The short ad shows selected actions; the full demonstration follows the editing session.

## Caption

EZ Scene Collab in Unity. Edit the scene from either Editor and see the changes on the other side.

## Recording note

Recorded locally in two Unity Editors using the original EZ Scene Collab package. Edits are automated. This is a recording of the Unity interface. Any speed changes in the short edit are documented in the recording details. The demo preserves the original timing. The music in the ad is an original instrumental made for this edit; it is not sound produced by the tool.

This material demonstrates the recorded workflow. It does not measure latency between separate computers. The Full Edition and the Firebase-based Lite Edition are separate products.
